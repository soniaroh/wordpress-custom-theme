# Custom WordPress Theme

A custom responsive WordPress theme built with PHP, HTML, CSS, and JavaScript. This project focuses on creating a clean, responsive website using WordPress theme development and reusable components.

## Features

* Custom WordPress theme
* Responsive design for desktop, tablet, and mobile
* Custom header and footer
* WordPress navigation menu
* Custom homepage template
* WordPress post integration
* Featured image support
* Reusable frontend components
* Responsive CSS
* Basic JavaScript interactions

## Technologies

* WordPress
* PHP
* HTML5
* CSS3
* JavaScript
